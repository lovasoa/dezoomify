# Documentation

## Use Dezoomify

Start with the [user guides](user/README.md) to choose an app, save an image,
or solve a download problem. They also generate the website help.

## Contribute

- [Development](development.md): setup, builds, and local development.
- [Architecture](architecture.md): the shared algorithm and ownership boundaries.
- [Contributing a format](CONTRIBUTING-format.md): add a parser and fixture.
- [Testing](testing.md): choose useful coverage.
- [Security](security.md): credentials and trust boundaries.
- [Operations](operations.md): releases, deployment, and rollback.
- [Licensing](licensing.md): imported-source grants and notices.
- [Privacy](privacy.md): user data handling.

Component READMEs cover local prerequisites and pitfalls. Use `cargo xtask --help`
for exact commands; source and generated bindings own API details.
