# Plans

Use this directory only for requested future work whose decisions or unfinished
steps need to survive the current chat. Multi-step work does not automatically
need a Markdown plan or an extra approval round.

Keep an actionable plan short, with the problem, unresolved decisions, and next
steps. Remove it when the work lands; Git keeps the history. Do not add status
ledgers, completion reports, or implementation diaries. Follow the root
[documentation rule](../AGENTS.md#documentation).
