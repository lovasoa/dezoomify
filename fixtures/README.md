# Product fixtures

Small image viewers, metadata, and tiles exercise discovery and saving across
the CLI, website, extension, and desktop app. Sharing the same sources makes
differences between products visible without relying on public websites.

Cases are grouped by image format and viewer variant, with common tile images
shared across cases. The [test infrastructure](../test/) serves them locally.
Older reproductions and their provenance live in [testdata](../testdata/).
