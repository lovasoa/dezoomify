# Busy Seadragon viewer

Synthetic GPL-3.0-or-later reproduction of the
[Versailles collection viewer](https://collections.chateauversailles.fr/?permid=permobj_7e3aa6fa-0ea9-49eb-b7e5-28c1d0255dde).
The viewer loads its query-based DZI and tiles after unrelated assets. No live
viewer object exposes the image, so extension discovery must use the resource
inventory. Native and website entry points use the same descriptor directly.
