# protocol-ts

- **Responsibility:** Provide TypeScript types and codecs generated by
  `crates/xtask` from the single Rust protocol source in
  `crates/dezoomify-protocol`.
- **Allowed dependencies:** Minimal runtime validation/serialization support
  required by generated code.
- **Forbidden responsibilities:** No hand-edited generated declarations,
  second schema source, business logic, UI state, browser APIs, or independent
  protocol versioning.
- **Interfaces and tests:** Export versioned commands, events, capability
  messages, and error envelopes. Require generation-clean checks, compile/type
  tests, golden fixtures, and round trips against `dezoomify-protocol`.
- **Migration source:** No direct import; protocol requirements are inferred from
  all migration roots and authored canonically in `crates/dezoomify-protocol`.
